# 旅行攻略技能（L1：完整操作说明）

按以下步骤执行：

1. 调用 `get_weather` 查询目的地天气，调用 `get_time` 获取当前时间；
2. 读取本技能的参考资料 `references/checklist.md`（L2 资源，用 load_skill_through_path 加载）；
3. 输出结构：
   - **天气提示**：一句话，结合天气给穿衣/雨具建议；
   - **行程安排**：上午 / 下午 / 晚上 各一项，写清地点与理由；
   - **出行清单**：从 checklist 中挑 3 项最相关的。
4. 全文不超过 200 字。
