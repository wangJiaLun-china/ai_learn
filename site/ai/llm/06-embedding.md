# Embedding 与向量检索

> 板块：LLM 基础 · 把文本变成向量，让「语义相近」变成「距离相近」—— RAG 的地基。

## Embedding 是什么 {#embedding}

- Embedding 模型把一段文本映射成固定维度的浮点向量（常见 512~3072 维）；
- 语义相近的文本，向量方向相近；
- 与聊天模型是**两类模型**：Embedding 模型只编码、不生成，便宜得多。

## 相似度 {#similarity}

| 度量 | 公式直觉 | 说明 |
| --- | --- | --- |
| 余弦相似度 | 两向量夹角的余弦 | 最常用，不受长度影响 |
| 点积 | 方向 × 长度 | 向量已归一化时等价于余弦 |
| 欧氏距离 | 两点直线距离 | 越小越近 |

## 检索流程 {#retrieval}

1. **切块（Chunking）**：按段落 / 标题 / 固定长度 + 重叠切分文档。块太大噪声多，太小丢上下文；
2. **向量化入库**：每块算 Embedding，存进向量库（pgvector、Milvus、Elasticsearch 等），同时保留原文和元数据；
3. **查询**：问题同样向量化，取 Top-K 最相似的块；
4. **重排（可选）**：用 Rerank 模型对候选精排；
5. **增强生成**：把检索到的块拼进提示词，让模型「开卷作答」并引用来源。

::: tip 💡 混合检索
纯向量检索对专有名词、编号、代码不敏感；生产中常把**关键词检索（BM25）+ 向量检索**结果融合，兼顾精确匹配与语义匹配。
:::
